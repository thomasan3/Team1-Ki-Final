## About
This immersive VR experience was developed as the final project for KINE 458: Virtual Worlds. The project explores the intersection of movement, technology, and performance, creating a dynamic environment using real-time motion capture with the Meta Movement and Interaction SDKs.
The project’s name references the Korean ritual tradition Ssitgim-gut, playing on the phrase “seeking gut.” While the name evokes themes of death and the life process, the project itself focuses on exploring human motion and interaction within a virtual space.
